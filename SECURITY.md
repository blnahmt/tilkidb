# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem.

Report it privately instead:

- on GitHub: the **Security** tab of this repository › **Report a vulnerability**, or
- by email to mail@bilenahmet.com.

Include the version, what you did, what happened, and what an attacker could do with it. You will get a reply within a week. Once a fix is released, you will be credited unless you prefer not to be.

## Supported versions

Only the latest release gets security fixes. The app offers it automatically, or get it from the Releases page.

## Scope

Examples of what counts:

- saved passwords or API keys leaking outside the OS keychain
- SQL running on a connection without the user asking for it
- SSH tunnels accepting an unknown host key
- the app opening links or files it shouldn't
